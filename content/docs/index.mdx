## 这个教程在做什么

我们从零写一个叫 **Mini Claude Code** 的命令行编程助手。

它做的事和 Claude Code 一样：你在终端里用自然语言描述任务，它自己读代码、
改代码、跑命令、告诉你改了什么。

但我们**不用任何 Agent 框架**——不用 Claude Agent SDK，不用 LangChain，
不用 OpenAI SDK 的 agent helper。我们只用最朴素的两样东西：

- Anthropic Messages API
- TypeScript 标准库

所有的编排逻辑——agent 循环、工具调度、参数校验、权限判定、上下文压缩、
子代理——都自己写。

<Callout type="idea" title="为什么要绕开现成的 SDK">
  框架会把关键决策藏起来：循环怎么转、上下文满了怎么办、工具冲突了听谁的。
  这些决策恰恰是一个 coding agent 最难的部分。亲手写一遍，你以后用
  Claude Code 时就知道它为什么这么设计了。
</Callout>

## 最终成果

全部代码在 `examples/mini-claude-code/`，克隆下来就能跑：

```bash
cd examples/mini-claude-code
pnpm install
export LLM_PROVIDER=anthropic
export ANTHROPIC_API_KEY=sk-ant-xxx
pnpm start
```

跑起来是一个 REPL：

```
› 看看 src/agent.ts 里 agent 循环是怎么写的

● 我先找到这个文件。
⏺ Read src/agent.ts
  ✓ Read

● 核心循环在 `run()` 方法里，整体是一个 while 循环：
  1. 调用模型
  2. 如果 stop_reason 不是 tool_use，任务结束
  3. 否则执行工具，把结果作为 user 消息喂回去，继续循环
```

它有这些能力：

- 读文件、写文件、精确编辑文件
- 按模式搜索文件名、按正则搜索文件内容
- 执行 shell 命令（带危险命令拦截）
- 维护待办清单，让多步任务可见
- 上下文满了自动压缩历史
- 危险操作需要你点头才执行

## 怎么用这个教程

**如果你想快速跑通**：直接看
[环境准备](/docs/getting-started/setup) 和
[第一个 Agent](/docs/getting-started/first-agent)，半小时能有一个能对话的 CLI。

**如果你想理解原理**：从
[架构总览](/docs/getting-started/architecture) 开始顺着读，
每章末尾的「小结」会点出这一章新增的认知。

**如果你想抄代码**：`examples/mini-claude-code/` 里的每一章产物都在，
带注释和测试，直接改就行。

<Callout type="warn" title="关于 API key">
  本教程需要你自己的 Anthropic API key。所有请求都由你的 key 发起，
  费用计入你的账户。动手前先看一眼
  [Anthropic 定价](https://platform.claude.com/docs/en/about-claude/pricing)，
  心里有个数再开始——agent 循环很容易在你不注意时多跑几轮。
</Callout>
